# Excel-Practical-Assignment_Superstore_Data
Excel Practical Assignment using Sample Superstore data, covering formulas, data cleaning, PivotTables, lookup functions, conditional formatting, and VBA basics.
Excel Practical Assignment – Sample Superstore Data Analysis
Author: Shubham Shah
Project Overview
This repository contains an Excel practical assignment built around the Sample Superstore dataset. The workbook demonstrates practical Excel skills for organizing, cleaning, formatting, analyzing, and summarizing sales data.

The work is organized into sections covering Excel formulas, data formatting, sorting and filtering, date calculations, logical functions, data cleaning, PivotTables, lookup formulas, conditional aggregation, conditional formatting, report consolidation, and introductory VBA macro concepts.

Workbook Contents
The workbook includes the following exercise sheets and supporting data sheets:
- Index – workbook index
- S1_Basics – basic formulas and calculations
- S2_Formatting – cell and number formatting
- S3_Sorting – sorting and filtering exercises
- S4_Dates – date and duration calculations
- S5_Logical – IF, AND, OR, and error-handling exercises
- S6_Cleaning – practical data-cleaning exercises
- S7_Pivot – PivotTable exercises
- S8_Lookup – lookup formula exercises
- S9_CondAgg – conditional aggregation formulas
- S10_CondFormat – conditional formatting exercises
- Jan, Feb, Mar – monthly supporting data for consolidation practice
- S11_Consolidate – report consolidation exercises
- S11_Subtotal – SUBTOTAL exercises
- S12_Macros – introductory macro and VBA concepts
- Orders, Returns, People – supporting Sample Superstore data tables
Excel Skills Covered
1. Basic arithmetic and statistical functions: SUM, MAX, MIN, SMALL, LARGE, MEDIAN
2. Transposing data and using TRANSPOSE
3. Counting functions: COUNT, COUNTA, COUNTBLANK
4. Status Bar calculations
5. Year-over-year growth and CAGR using POWER
6. Cell formatting, number formats, Wrap Text, alignment, and Format Painter
7. Sorting numbers, dates, text, colors, and multiple levels
8. Date formulas and duration calculations
9. Logical functions: IF, AND, OR, IFERROR
10. Data cleaning, text functions, duplicate handling, Text to Columns, and Find & Replace
11. PivotTables, grouping, and conditional formatting
12. Lookup formulas: VLOOKUP and HLOOKUP
13. Conditional aggregation: COUNTIF, SUMIF, AVERAGEIF, COUNTIFS, SUMIFS
14. Consolidation and SUBTOTAL
15. Introduction to Excel Macros and VBA

How to Use
1. Download or clone this repository.
2. Open Excel_Practical_Assignment.xlsx in Microsoft Excel.
3. Start with the Index sheet.
4. Navigate through the exercise sheets to review the practical work.
5. Use the supporting data sheets for the relevant analysis and practice.
Notes
- The main deliverable is the .xlsx workbook.
- The S12_Macros sheet covers introductory macro/VBA topics. The submitted workbook is an .xlsx file, which does not store embedded VBA projects. If you create and submit working VBA macros, save a separate macro-enabled copy as .xlsm.
- If you make changes to the workbook, save and upload the latest version to this repository.
