# Excel Practical Assignment - Sample Superstore Data Analysis

**Author:** Shubham Shah

An Excel practical assignment built on the Sample Superstore dataset. It covers formulas, data cleaning, PivotTables, lookup functions, conditional formatting and the basics of VBA macros.

---

## Project Overview

This repository contains an Excel practical assignment built around the Sample Superstore dataset. The workbook demonstrates practical Excel skills for organizing, cleaning, formatting, analyzing and summarizing sales data.

The work is split into sections covering:

- Excel formulas and basic calculations
- Data formatting, sorting and filtering
- Date calculations and logical functions
- Data cleaning
- PivotTables
- Lookup formulas and conditional aggregation
- Conditional formatting
- Report consolidation and SUBTOTAL
- Introductory VBA / macro concepts

## Excel Skills Covered

1. Basic arithmetic and statistical functions: SUM, MAX, MIN, SMALL, LARGE, MEDIAN
2. Transposing data with TRANSPOSE
3. Counting functions: COUNT, COUNTA, COUNTBLANK
4. Status Bar calculations
5. Year-over-year growth and CAGR using POWER
6. Cell formatting, number formats, Wrap Text, alignment and Format Painter
7. Sorting numbers, dates, text and colors, including multiple levels
8. Date formulas and duration calculations
9. Logical functions: IF, AND, OR, IFERROR
10. Data cleaning: text functions, duplicate handling, Text to Columns, Find & Replace
11. PivotTables, grouping and conditional formatting
12. Lookup formulas: VLOOKUP and HLOOKUP
13. Conditional aggregation: COUNTIF, SUMIF, AVERAGEIF, COUNTIFS, SUMIFS
14. Consolidation and SUBTOTAL
15. Introduction to Excel macros and VBA

## How to Use

1. Download or clone this repository.
2. Open `Excel_Practical_Assignment.xlsx` in Microsoft Excel.
3. Start with the `Index` sheet.
4. Move through the exercise sheets to review the practical work.
5. Use the supporting data sheets for the related analysis and practice.

## Notes

- The main deliverable is the `.xlsx` workbook.
- The `S12_Macros` sheet covers introductory macro and VBA topics. An `.xlsx` file cannot store an embedded VBA project, so if you create working macros, save a separate macro-enabled copy as `.xlsm`.
- If you change the workbook, save it and upload the latest version to this repository.
